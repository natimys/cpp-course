---
title: "Переменные и типы данных"
---

Компьютер умеет считать, но ему надо где-то держать числа и другие данные. Для этого в программе есть переменные.

Переменная похожа на подписанную коробку. Внутри лежит значение, а имя на коробке помогает понять, что там хранится. Только коробки бывают разными: в одну кладём целое число, в другую текст, а в третью ответ «да» или «нет».

## Создаём переменную

```cpp
int age = 16;
```

Здесь `int` говорит, какого типа данные хранит переменная, `age` - её имя, а `16` - начальное значение. В C++ сначала указывают тип, затем имя и через `=` задают значение.

Общий вид такой:

```cpp
тип имя = значение;
```

Например, `int age = 16;` создаёт переменную `age` типа `int` и кладёт в неё число 16. Точка с запятой в конце обязательна. C++ не читает мысли и не догадается, где закончилась команда.

В Python переменную можно создать просто присваиванием, а тип определяется по значению. В C++ тип пишут явно: `int` для целых чисел, `double` для дробных и так далее. Само значение после объявления можно менять, но тип переменной остаётся прежним.

Не оставляй переменную неинициализированной: сначала задай ей безопасное начальное значение, например ноль для `int`. Потом при необходимости запиши новое:

```cpp
int score = 0;
score = 10;
```

## Имена переменных

Имя должно подсказывать, что лежит в переменной. Для примера, `player_score` хранит очки игрока, а `number_of_lives` - количество жизней:

```cpp
int player_score = 100;
int number_of_lives = 3;
```

C++ и Python различают регистр букв: `score`, `Score` и `SCORE` - разные имена. Если имя состоит из нескольких слов, разделяй их символом `_`, например `player_score`.

## Типы данных

`int` хранит целые числа, `double` - числа с дробной частью, `char` - один символ, `bool` - истину или ложь, а `std::string` - текст. Чтобы типы и значения не были абстрактными словами, представь их как разные виды коробок: форма коробки подсказывает, что туда можно положить. В Python тип переменной можно не писать, но в C++ его указывают при создании явно.

Чтобы использовать `std::string`, подключи заголовок:

```cpp
#include <string>
```

`std::string name = "Саша";` создаёт текстовую переменную, а `char grade = 'A';` хранит один символ. Строку пишут в двойных кавычках, символ - в одинарных. Это не украшение: `"A"` и `'A'` имеют разные типы.

## Значение можно менять

Значение можно менять:

```cpp
int score = 10;
score = 15;
```

А тип - нет: переменную `score` нельзя сначала создать как `int`, а потом превратить в текст. В Python тип может измениться при повторном присваивании, в C++ переменная сохраняет объявленный тип. Если число должно оставаться постоянным, добавь `const`:

```cpp
const int days_in_week = 7;
```

После создания `days_in_week` менять уже нельзя. Компилятор сообщит об ошибке, если попробовать.

## Соберём всё в программе

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "Саша";
    int age = 16;
    double height = 1.72;
    bool likes_cpp = true;

    std::cout << name << ", возраст: " << age << '\n';
    std::cout << "Рост: " << height << '\n';
    std::cout << "Нравится C++: " << likes_cpp << '\n';
}
```

`int age = 16;` создаёт целочисленную переменную; `double height = 1.72;` хранит дробное число. Для текста есть `std::string`, а для ответов «да» или «нет» - `bool`.

`std::cout` отправляет значения в консоль. До вывода `likes_cpp` равно `true`, но поток по умолчанию показывает его как `1`, а `false` как `0`. Пока достаточно запомнить этот фокус. В следующей статье разберём [ввод и вывод](/cpp-course/input-output/).
