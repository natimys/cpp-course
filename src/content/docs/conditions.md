Пока программа выполняет команды одну за другой. Но часто хочется, чтобы она выбирала, что делать дальше: пустить игрока в игру, если ему хватает возраста, или не делить конфеты, когда друзей оказалось ноль.

В Python программа часто записывается как последовательность команд с отступами. В C++ после `if` условия ставят фигурные скобки, чтобы отметить начало и конец блока. Тело блока обычно выделяют отступом, как в Python, но сами фигурные скобки всё равно обязательны.

Например, в Python это выглядело бы так:

```python
if age >= 18:
    print("Вход разрешён.")
```

Внутри фигурных скобок располагаются команды блока. Точка с запятой завершает каждую команду.

```cpp
int age = 18;

if (age >= 18) {
    std::cout << "Вход разрешён.\n";
}
```

Если проверка верна, программа выполняет команду внутри скобок. Если нет - идёт дальше.

## Сравниваем значения

Тип `bool` хранит одно из двух значений: `true` или `false`. В Python для этого есть такой же тип `bool`. Условие внутри `if` должно дать ответ: выполнять блок кода или пропустить его.

| Проверка | Значение |
|---|---|
| `a == b` | `a` равно `b` |
| `a != b` | `a` не равно `b` |
| `a < b` | `a` меньше `b` |
| `a > b` | `a` больше `b` |
| `a <= b` | `a` меньше или равно `b` |
| `a >= b` | `a` больше или равно `b` |

В C++ оператор `=` присваивает значение переменной, а `==` сравнивает два значения. В Python они работают так же. Компилятор не всегда угадает, что ты имел в виду.

## `else` и `else if`

В Python после `if` условие заканчивается двоеточием, а блок задают отступы. В C++ условие пишут в круглых скобках, а блок обрамляют фигурными:

```cpp
if (age >= 18) {
    std::cout << "Можно войти.\n";
} else {
    std::cout << "Пока рано.\n";
}
```

`else` задаёт запасной вариант: если условие в `if` ложно, выполняется блок после `else`.

В Python цепочка альтернатив записывается через `elif`. В C++ она называется `else if`:

```cpp
if (score >= 90) {
    std::cout << "Отлично!\n";
} else if (score >= 60) {
    std::cout << "Зачёт.\n";
} else {
    std::cout << "Нужно попробовать ещё раз.\n";
}
```

Условия идут сверху вниз. `else if` выполняется, только если предыдущие условия ложны. При первом совпадении программа пропускает остальные ветки.

## Несколько условий сразу

Логические операторы знакомы и по Python: `&&` означает «и», `||` - «или», `!` - «не». Они позволяют соединять условия. В C++ это специальные символы, а в Python пишут слова `and`, `or` и `not`.

```cpp
if (age >= 18 && has_ticket) {
    std::cout << "Проходи.\n";
}
```

Проверки возрастного ограничения и билета соединены через `&&`. Для входа должны быть истинны оба условия.

## Проверяем ввод перед делением

В статье [«Арифметические операции»](/cpp-course/arithmetic/) мы выяснили, что делить на ноль нельзя. Значит, проверим количество друзей перед расчётом:

```cpp
#include <iostream>

int main() {
    int candies = 0;
    int friends = 0;

    std::cout << "Сколько конфет? ";
    std::cin >> candies;
    std::cout << "Сколько друзей? ";
    std::cin >> friends;

    if (friends > 0) {
        std::cout << "Каждому достанется " << candies / friends << '\n';
        std::cout << "Останется " << candies % friends << '\n';
    } else {
        std::cout << "Друзей должно быть больше нуля.\n";
    }
}
```

`std::cin` и `std::cout` мы разбирали в статье [«Ввод и вывод»](/cpp-course/input-output/). Здесь программа сначала читает значения, потом проверяет `friends`, и только после этого делит.
