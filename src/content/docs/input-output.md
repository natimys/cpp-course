Программа может считать всё что угодно, но если она не умеет разговаривать с человеком, радости мало. Вывод показывает результат, ввод позволяет передать программе данные.

Для работы с консолью подключи заголовок `<iostream>`:

```cpp
#include <iostream>
```

## Выводим данные

За вывод отвечает `std::cout`:

```cpp
std::cout << "Привет!" << '\n';
```

Для `std::cout` символ `<<` отправляет значение в поток вывода. Несколько частей можно передать подряд. В Python для вывода обычно используют `print()`, но здесь элементы соединяем отдельно этим оператором.

```cpp
int age = 16;
std::cout << "Мне " << age << " лет" << '\n';
```

Строки можно записывать в вывод через `std::cout`. Вместо него часто используют `std::endl`: он тоже переводит строку, но вдобавок принудительно очищает буфер. Для обычного перехода достаточно символа `\\n`.

## Получаем ввод

Для чтения с клавиатуры есть `std::cin`:

```cpp
int age = 0;
std::cout << "Сколько тебе лет? ";
std::cin >> age;

std::cout << "Тебе " << age << " лет.\n";
```

`>>` читает следующий фрагмент ввода до пробела и записывает его в переменную. Перед чтением мы заранее создаём `age` как `int`, то есть сообщаем программе, что ждём целое число.

`std::cin >> name` читает только до пробела. Если ввести `Иван Иванов`, в `name` попадёт только `Иван`. Для полной строки с пробелами используй `std::getline`:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string full_name = "";
    std::cout << "Как тебя зовут? ";
    std::getline(std::cin, full_name);

    std::cout << "Привет, " << full_name << "!\n";
}
```

В Python ввод строки обычно пишут так: `name = input()`. Здесь мы вызываем `std::getline`, передаём ей поток `std::cin` и переменную, куда положить строку. Идея та же: прочитать ввод пользователя и сохранить его в переменную. Запись функции отличается, потому что в C++ всё явно привязано к потоку ввода.

## Подводный камень с `getline`

Если сначала прочитать число через `>>`, а потом вызвать `std::getline`, строка может оказаться пустой: после числа во входном потоке остаётся символ Enter, и `getline` сразу на нём останавливается.

```cpp
int age = 0;
std::cin >> age;
std::string name = "";
std::getline(std::cin, name); // прочитает оставшийся Enter
```

Перед `std::getline` нужно убрать остаток текущей строки. Для этого подключим `<limits>` и пропустим символы до Enter:

```cpp
#include <iostream>
#include <limits>
#include <string>

int main() {
    int age = 0;
    std::string name = "";

    std::cout << "Возраст: ";
    std::cin >> age;
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

    std::cout << "Имя и фамилия: ";
    std::getline(std::cin, name);

    std::cout << name << ", тебе " << age << " лет.\n";
}
```

`ignore` убирает остаток строки до Enter. `std::numeric_limits<std::streamsize>::max()` задаёт, сколько символов можно пропустить. Если ввести текст вместо числа, чтение завершится ошибкой; обработку ошибок разберём отдельно.

## Мини-программа

Попросим пользователя ввести два целых числа и выведем их сумму:

```cpp
#include <iostream>

int main() {
    int first = 0;
    int second = 0;

    std::cout << "Введи два числа: ";
    std::cin >> first >> second;

    std::cout << "Сумма: " << first + second << '\n';
}
```

Здесь `first` и `second` - [переменные](/cpp-course/variables/), а `first + second` использует [оператор сложения](/cpp-course/arithmetic/).

## Что попробовать

1. Спроси у пользователя имя и поздоровайся с ним.
2. Считай два числа и выведи результат сложения, вычитания и умножения.
3. Попроси ввести возраст и выведи, сколько лет будет через год.
4. Попробуй вместо числа ввести слово. Посмотри, что произойдёт. Пока не чини, просто запомни наблюдение.

Для задания с возрастом понадобятся [арифметические операции](/cpp-course/arithmetic/), а чтобы принимать решения по введённым данным - [условия](/cpp-course/conditions/).
