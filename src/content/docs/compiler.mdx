# Компилятор C++ в браузере

Не хочется сейчас настраивать компилятор на компьютере? Потренируйся прямо на сайте: редактор собирает программу и запускает её в браузере, без отправки исходного кода на сервер курса.

<Compiler />

## Как пользоваться

1. Напиши или измени код в редакторе.
2. Если программа читает данные через `std::cin`, укажи их в поле **Ввод программы (stdin)**. Каждую строку ввода отделяй клавишей Enter.
3. Нажми **Скомпилировать и запустить**. Сообщения компилятора появятся в окне результата вместе с выводом программы.
4. Если программа зациклилась, останови её кнопкой **Остановить**. На всякий случай выполнение автоматически прерывается через 10 секунд.

При самом первом запуске браузер скачает компилятор Clang в WebAssembly — примерно 23 МБ. Это может занять время; следующие запуски используют кэш браузера. Для загрузки нужна сеть. Сборка и выполнение кода происходят в Web Worker на твоём устройстве, сервер получает только статические файлы компилятора.

Компилятор использует Clang 21 и стандарт C++20. Среда учебная и ограниченная: поддерживается одна программа с `main`, нет доступа к файлам и сети, нескольких исходных файлов и интерактивного ввода во время выполнения. Данные для `std::cin` передаются заранее через stdin. Не вставляй в песочницу секреты и не запускай чужой код, которому не доверяешь.

> Онлайн-компилятор удобен для первых опытов и небольших задач. Для полноценной разработки, работы с проектами и отладки установи локальный компилятор по инструкции в разделе [Установка](/cpp-course/installation/).
