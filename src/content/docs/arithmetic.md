Переменные умеют хранить числа. Теперь выполним с этими числами пару вычислений.

Пусть у нас есть два целых числа:

```cpp
int a = 17;
int b = 5;
```

В Python вычисления строятся так же: числа соединяют операторами `+`, `-`, `*`, `/` и `%`. Например, `a + b` складывает значения переменных. В C++ переменные нужно заранее создать и указать их тип, как в статье [«Переменные и типы данных»](/cpp-course/variables/).

`%` возвращает остаток от деления. Например, 17 делится на 5 три раза, а в остатке остаётся 2.

## Основные операции

| Операция | Знак | Пример | Результат |
|---|---:|---|---:|
| Сложение | `+` | `a + b` | `22` |
| Вычитание | `-` | `a - b` | `12` |
| Умножение | `*` | `a * b` | `85` |
| Деление | `/` | `a / b` | `3` |
| Остаток от деления | `%` | `a % b` | `2` |

С остатком просто: при делении 17 на 5 получится три целых раза и остаток 2.

## Целочисленное деление

Операция деления работает по-разному в зависимости от типов. Если `int` делят на `int`, результат будет целым: `17 / 5` даст `3`. Дробная часть просто отбросится, без округления. Чтобы получить `3.4`, хотя бы одно из чисел должно быть типа `double`, например `17.0 / 5`.

`17 / 5` и `17.0 / 5` показывают, почему важно выбирать тип правильно. Подробнее про `int` и `double` - в статье [«Переменные и типы данных»](/cpp-course/variables/).

## Сокращённая запись

`+=` добавляет значение справа к переменной слева и сохраняет сумму обратно в неё. Например, `score += 5` короче, чем `score = score + 5`. Похожие сокращения есть у вычитания (`-=`), умножения (`*=`) и деления (`/=`).

## Остаток и чётность

Для проверки чётности можно взять остаток от деления числа на 2:

```cpp
int number = 14;
int remainder = number % 2;
```

Если `remainder` равен нулю, число делится на 2 без остатка и является чётным. Иначе оно нечётное. Как выбрать действие по результату такой проверки, смотри в статье [«Условия»](/cpp-course/conditions/).

## Приоритет операций

В Python действует тот же порядок действий, что и в обычной математике: умножение выполняется раньше сложения. Поэтому `2 + 3 * 4` даст `14`.

```cpp
int result = 2 + 3 * 4; // получится 14
```

Скобки меняют порядок, как и в математике:

```cpp
int result = (2 + 3) * 4; // получится 20
```

Если не уверен в порядке операций, поставь скобки. Так выражение будет понятнее и человеку, и компилятору.

## Важное про деление

Делить на ноль нельзя. Если делитель вводит пользователь, проверь его до вычисления. Считай значения через [ввод](/cpp-course/input-output/), затем используй [условие](/cpp-course/conditions/), чтобы разрешить деление только при ненулевом делителе.

## Что попробовать

1. Создай две переменные типа `int` и выведи сумму, разность и произведение.
2. Проверь, чем отличаются `17 / 5` и `17.0 / 5`.
3. Вычисли остаток от деления своего любимого числа на 2.
4. Пользователь вводит число конфет и количество друзей. Раздели конфеты поровну и выведи, сколько конфет достанется каждому и сколько останется.

Ввод чисел разобран в статье [«Ввод и вывод»](/cpp-course/input-output/). А проверить, можно ли вообще делить на количество друзей, поможет статья [«Условия»](/cpp-course/conditions/).
